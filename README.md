# 斗鱼多屏（douyu-desktop）

Windows 桌面端多直播间客户端。当前是 **P2 多路播放 + P3 B 站接入 + P4 虎牙 HLS 播放 + 首页快速开始**：斗鱼/B 站/虎牙最多 4 路同屏；首页汇总特别关注、我的关注和最近观看；斗鱼/B 站每路实时弹幕；单路重载/关闭、画质切换、粉丝团签到。

多平台评估见 [docs/platform-support.md](docs/platform-support.md)：B 站已落地；虎牙已接入登录与 HLS 播放（本地滚动列表代理续播一次性签名），弹幕待后续。

## 技术栈

- Electron 38 + electron-vite 6
- React 19 + TypeScript 5.9
- hls.js / mpegts.js（本地打包，不用 ReactPlayer）
- TanStack Query
- Zod（IPC 边界校验）
- Vitest

## 运行

```bash
npm install
npm run dev
```

检查：

```bash
npm run typecheck
npm run lint
npm run check:boundaries
npm run test
```

构建：

```bash
npm run build
```

打包 Windows：

```bash
npm run package:dir   # release/win-unpacked，可直接运行
npm run package       # NSIS 安装包
```

打包成功后终端会直接打印绝对路径，例如：

```text
打包成功（NSIS 安装包）
版本：0.8.8
输出目录：F:\FrontEnd\code\douyu-desktop\release
安装包地址：F:\FrontEnd\code\douyu-desktop\release\douyu-desktop-0.8.8-x64.exe
免安装版地址：F:\FrontEnd\code\douyu-desktop\release\win-unpacked\斗鱼多屏.exe
打包记录：F:\FrontEnd\code\douyu-desktop\release\package-result.json
```

同时会写入 `release/package-result.json`，记录版本、输出目录、安装包和免安装版路径。打包失败时不会打印成功地址，并返回非零退出码。

如果 Windows 占用了 `release/win-unpacked`，先关闭正在运行的 app，或换输出目录：

```powershell
$env:PACKAGE_OUTPUT_DIR = 'release-nsis'
npm run package
```

`PACKAGE_OUTPUT_DIR` 支持相对项目根目录的路径，也支持绝对路径。

## 多路操作

- 输入房间号后点“播放/添加”，追加到网格；最多 4 路
- 顶部是唯一的操作栏：左侧品牌，中间依次是“直播”页签、房间号输入、历史、播放/添加、清空、签到和账号登录，右侧为最小化/最大化/关闭；顶栏除按钮、输入框、账号菜单等交互控件外均可拖拽，双击品牌或顶栏空白拖拽区也可最大化/还原
- 不再有左侧导航和右侧任务栏；直播画面从顶栏下方 6px 开始，四路时也使用整窗宽度
- 每张卡片右上角可单独“重新解析”或关闭
- 播放中媒体时间连续 8 秒不前进时，卡片内提示“直播可能卡住了”，提供“重新加载/继续等待”；不自动刷新，避免误判打断播放
- 视频底部控制条贴底显示，默认隐藏；鼠标进入画面显示，离开画面立即收起，鼠标静止 4 秒也会收起
- 控制条包含画面播放/暂停、音量、弹幕显示/暂停、画质、HLS 和右侧齿轮；画质/HLS 只作用于当前这一路并自动重新解析
- 点击画面本身不再暂停/播放，画面暂停按钮固定放在音量键左侧
- 4 路紧凑布局会收起弹幕暂停按钮，画面暂停仍保留；弹幕暂停可从齿轮打开的设置面板操作
- 画面左上角 LIVE/ROOM 标识不再常驻，和底部控制条一起在鼠标进入时出现、离开或静止 4 秒后隐藏，避免与卡片标题重复
- 新加入的房间默认开启声音，已有房间的静音状态保持不变；每路可独立静音/取消静音，多路可同时出声；拖动某一路音量会取消该路静音（拖到 0 则静音该路）
- 新房间默认按原画 + FLV 解析，加入后可在底部切换到高清/超清/蓝光，或尝试 HLS
- 3 路时会显示“再加一路”空位；顶栏“清空”一次关闭全部
- 首页“特别关注”先展示斗鱼官方的 `is_special` 特别关注，官方卡片右侧星标为只读；其余关注/历史行点星标可补充本地置顶，本地置顶保存在 `%USERPROFILE%\.douyu-desktop\special-follows.json`，多窗口通过 `special:changed` 同步
- 首页“特别关注”优先，且“我的关注”会排除所有特别关注房间，两区不重复；两个区域都按关注接口 `online` 的热度降序排列，热度相同才比较开播状态和名称
- 首页顶部只保留一行数字概览（我的关注/直播/特别关注/历史），其中“关注”数不含特别关注；卡片左侧为 16:9 缩略图，整卡高度 92px
- 首页卡片关注接口返回封面时显示官方房间图，最近观看会复用同一房间的关注封面；没有封面或图片加载失败时显示平台图标占位，不出现破图
- 首页“我的关注”使用当前斗鱼账号读取官方关注列表，按热度降序排列；只有斗鱼账号会同步关注，B 站/虎牙房间仍可从最近观看打开；关注接口最多读取 5 页 / 100 个房间，避免首页启动过慢
- 点首页任意房间卡片会先加入直播再切回“直播”页签；房间已经在播放时只切换页签，不重复添加；4 路上限、重复房间和登录失败仍沿用原有顶栏错误提示
- 切到首页会暂停所有正在播放的视频并记住播放状态；返回直播只恢复之前正在播放且用户没有手动暂停的线路，避免首页后台混音
- 顶栏“历史”按最近访问时间倒序列出房间标题、主播、平台、房间号和访问时间；点击记录可直接重新加入，重复访问只保留一条并更新时间
- 历史卡片左侧为平台徽标（本地官方 favicon：斗鱼鱼形、B站 TV、虎牙虎形，来源见 [assets/platforms/README.md](src/renderer/src/assets/platforms/README.md)），整行垂直居中；主播名 13.5px 橙色、标题 15.5px 白色、房间号和时间 10.5px
- 历史支持单条删除、管理多选（全选/删除 N）、全部清空；清空需二次确认，3 秒未确认自动回退
- 桌面端默认禁止选中界面文本（顶栏、按钮、历史、弹幕和播放覆盖层）；房间/任务输入框仍可编辑和选中；错误提示通过 `.selectable` 保留复制排障能力
- 历史保存在用户主目录的全局文件 `%USERPROFILE%\.douyu-desktop\room-history.json`（非安装目录、非 Electron userData），按 `${platform}:${roomId}` 去重，最多保留 30 条；首次启动会把旧 `localStorage`（v2/v1）和开发模式 `http://localhost:5173` 的历史合并进全局文件，成功后再清除本地副本；旧 v1 记录自动迁移；多窗口通过 main 广播同步；点击外部或 Esc 关闭
- 顶栏“签到”打开居中任务弹窗，不再占用右侧列；弹窗支持关闭按钮、点击遮罩或 Esc 关闭
- 签到默认在每天首次启动后自动在后台跑一次；成功/部分完成/跳过会记录当天，同账号当天不再自动重复，失败下次启动可重试；可在弹窗内关闭“每天自动签到”，设置写入 `localStorage`（`douyu-desktop.auto-sign.v1`）
- 手动或自动签到都在独立后台任务里运行；关闭签到面板、切换直播、最小化应用都不会中断，顶栏按钮实时显示“签到 x/y”和“已签到/部分失败”
- 同一时间只允许一个签到任务；后台运行中再次触发会返回 BUSY，不会重复签到；请求仍走现有主进程限速，不阻塞播放和弹幕
- 每路视频左下角显示实时弹幕；连接中/重连/失败会在右上角提示
- 控制条最右侧齿轮打开全局弹幕设置面板；面板固定在窗口右下角，所有画面立即同步，点击外部或 Esc 关闭
- 画质下拉使用深色菜单和显式文字颜色，未选中项保持高对比，不再出现深色字贴深色底
- 面板里的“清屏”会清空四路当前弹幕，不关闭弹幕连接

## 弹幕说明

- 弹幕连接是匿名只读 WebSocket：斗鱼只使用 main 注入的设备 Cookie，不读取账号 Cookie；B 站使用 main 解析的匿名 token
- 斗鱼：`danmuproxy.douyu.com:8502` visitor 登录 → `joingroup`（`gid` 为空）→ `sub/mt@=o` → 每 20 秒 `mr`；没有 `sub` 时只能收到历史/房间状态
- 斗鱼 `wsproxy` 的 `hischatmsg` 是历史消息，不是实时聊天；实时聊天解析 `chatmsg`
- B 站：legacy `Danmu/getConf` 取 token/host，16 字节包头，op 7 认证、op 2 心跳、op 5 消息；协议版本 2 用 zlib 解压
- 聊天和礼物默认从右向左飞行；进场提示默认关闭，可在“显示内容”里打开，避免进场消息刷屏
- 默认字号 20px，最低 16px；字号调小后仍不会退回到 12px 的不可读尺寸
- 按实际文本宽度占用轨道，测量前先应用字号；轨道释放前不会重复占用
- 同轨相邻弹幕额外保留约 40px 横向安全间距，高流量时按 70ms 间隔逐条投放，避免一帧堆出弹幕墙
- 修改速度、字号、位置或不透明度时，正在飞行的弹幕不会清空：字号/轨道变化通过 top/font-size 过渡重排，速度变化通过 playbackRate 连续变速
- 同屏密度改变后由后续投放使用新的轨道间距，正在飞行的弹幕保持原位，不会被清空
- 屏蔽类型和显示内容开关只影响后续弹幕及等待队列；已经出现的弹幕不会被强制清除，粉丝牌/昵称切换会同步更新当前弹幕
- 聊天、进场、礼物分别用不同样式；粉丝牌、贵族、房管、超管有标识，粉丝牌/昵称默认不展示
- 斗鱼 `col` 是 1–7 的颜色索引：1 红、2 蓝、3 绿、4 橙、5 紫、6 粉、7 七彩（整条丝滑渐变）；缺省为白色，未知小索引回退白色
- 设置项对齐斗鱼网页播放器：弹幕速度、不透明度、弹幕字号、弹幕位置、弹幕屏蔽（大号/顶部/底部/角色）、屏蔽超级留言弹幕、精简弹幕

- 颜色不会单独触发过滤；看不到彩色弹幕时先检查“精简弹幕”和角色/大号等整条消息过滤开关
- `col=7` 的七彩弹幕用整条文字渐变渲染；必须关闭继承的黑色 `text-shadow`，否则透明填充会被黑色阴影盖住；其他未知小索引不再被误当成深色 RGB，避免弹幕发黑不可见
- “弹幕位置”限制在播放器安全区内：全屏、1/4 屏、上半屏、下半屏；1/4 屏保留顶部第一行轨道
- “大号”按高等级消息过滤（当前阈值 30 级）；顶部/底部按协议 `pos` 字段过滤
- 设置写入 `localStorage`（v2）；暂停状态不持久化，重启后自动恢复播放
- 旧 v1 设置会一次性迁移：140% 速度/字号回到 100%，粉丝牌/昵称关闭，其余位置和透明度保留
- 礼物消息优先使用协议里的礼物名称；缺少名称时显示“送出礼物 ×N”

## 稳定性与加载优化

- 签到结果携带执行账号和模拟运行标记；切换账号不会把上一个账号的结果记到当前账号，模拟运行不占用当天自动签到记录。
- 账号文件首次读取共享同一个 Promise，保存操作串行执行，避免多账号同时刷新时争用临时文件；一次保存失败不会堵住后续保存。
- 每次添加的播放器都有独立实例标识；关闭或清空后，旧重载请求的结果、错误和结束回调不能覆盖新实例。
- HLS 网络/媒体故障最多恢复三次，只有视频实际连续推进 10 秒后才重置恢复次数；解析成功的播放列表不会单独重置计数。关闭播放器会清理恢复和自动播放定时器。
- 虎牙切片仍保留 404 的发布等待重试；重试耗尽后与 403 一样失效旧模板，下一次请求重新获取列表。旧请求迟到的错误不会清掉已经刷新过的模板。
- HLS / FLV 库按实际播放格式动态加载，渲染层生产构建开启压缩；异步加载期间关闭房间不会再创建播放器。
- 斗鱼房间资料、B 站标题和主播信息请求最多等待 1 秒且不重试；超时使用默认标题/主播名继续播放，取流请求仍保留原有重试策略。
- 上述账号隔离、并发写入、重载竞态、播放器恢复及元信息超时均有自动回归测试，可通过 `npm run test` 验证。

## 架构约束

```text
main → core → shared
renderer → preload → main
renderer → 匿名弹幕 WebSocket（斗鱼设备 Cookie / B 站 token 由 main 下发）
```

- `core` 不依赖 Electron/React/Node 内置模块
- `renderer` 不依赖 Electron/Node/core/main
- 弹幕协议编解码在 `shared/douyu` 和 `shared/bilibili`，纯函数、可单测，供 renderer 复用
- 弹幕飞行引擎、过滤规则、轨道布局在 `renderer/features/danmaku`；布局和过滤是纯函数
- 弹幕设置通过 Context 全局共享，持久化在 renderer `localStorage`，不进入 main/IPC
- 房间历史通过 main 的 `JsonRoomHistoryStore` 写入用户主目录全局 JSON；renderer 只通过 `history:load` / `history:merge` / `history:remove` / `history:clear` IPC 读写；main 串行化读改写，并在变更后广播 `history:changed`，多窗口不会用旧快照互相覆盖
- 首页关注列表由 main 的 `HomeService` 使用当前账号会话调用斗鱼关注接口，cookie 不进入 renderer；renderer 只通过 `home:followed` 拿 `FollowedRoom[]`
- 特别关注由 main 的 `JsonSpecialFollowStore` 原子写入 `%USERPROFILE%\.douyu-desktop\special-follows.json`；置顶/取消通过 `special:toggle`，变更后广播 `special:changed`，各窗口各自订阅并更新
- 开发模式的历史 origin 是 `http://localhost:5173`，打包版是 `file://`，两者 localStorage 不互通；main 在首次启动用临时隐藏页读取开发 origin，并写入一次性迁移标记
- Cookie、`dyToken`、CSRF 只在 main；renderer 只拿 `AccountSummary` / `PlatformLoginStatus`；斗鱼弹幕设备 Cookie 由 main 注入，B 站弹幕只下发 token
- B 站/虎牙登录分区由 main 持有；renderer 只能触发登录/退出并读取昵称、头像和登录状态，不接触 Cookie
- 主进程 HTTP 统一 `credentials: 'include'`，B 站解析请求才能携带登录分区的 `SESSDATA`
- 任务通过 `TaskDefinition + TaskRunner + TaskRegistry` 注册，不在 UI 里写业务
- 签到运行状态由 main 的 `TaskService` 持有，通过 `tasks:state` / `tasks:progress` 广播；renderer 的 `TasksProvider` 在应用级订阅，弹窗关闭不会丢进度，同一时刻只允许一个运行中的 run
- 请求级限速/重试在 `DouyuHttpClient`，任务级超时/取消在 `TaskRunner`
